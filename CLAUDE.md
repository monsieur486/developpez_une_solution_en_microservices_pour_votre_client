# Conventions du projet

## Commits Git

- **Ne pas ajouter** de trailer `Co-Authored-By: Claude` (ni aucune autre
  mention de Claude / Anthropic) dans les messages de commit.
- Messages de commit en français, explicites, au format Conventional Commits
  (ex. `test(notes): ...`, `refactor(patients): ...`).
- Workflow : commits directs sur `master`, push à la fin du chantier.
